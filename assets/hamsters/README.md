# PNG Almarts27

Положите сюда оригинальные изображения, которым хотите назначить выражения. Те же файлы можно добавить через окно «Коллекция PNG».

| Имя | Выражение |
|---|---|
| `neutral.png` | Нейтральное |
| `happy.png` | Улыбка |
| `laughing.png` | Смех |
| `angry.png` | Нахмуренные брови |
| `sad.png` | Грустное выражение |
| `crying.png` | Плачущее выражение |
| `surprised.png` | Удивление |
| `smirk.png` | Ухмылка |
| `suspicious.png` | Поднятая бровь |
| `sleepy.png` | Глаза закрыты дольше секунды |

`neutral.png` нужен для запуска вывода. Он используется при потере лица и вместо любой незаполненной ячейки. Прозрачность PNG сохраняется. Чтобы фон был виден вокруг рисунка, загрузите PNG с прозрачными полями.
