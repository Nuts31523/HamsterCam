# HamsterCam

Приложение для Windows 10/11 x64, которое переключает загруженные PNG по мимике и передаёт их в системную **OBS Virtual Camera**. Анализ выполняется на CPU. Исходные кадры доступны только локальному предпросмотру и MediaPipe. HamsterCam не сохраняет и не отправляет видео.

## Запуск готовой сборки

1. Установите [OBS Studio для Windows](https://obsproject.com/download). Компонент виртуальной камеры устанавливается вместе с OBS. Если устройство отсутствует, выполните [инструкцию OBS для Windows](https://obsproject.com/kb/virtual-camera-troubleshooting).
2. Запустите `HamsterCam.exe`. Храните папку `_internal` рядом с EXE.
3. Выберите физическую камеру. В «Коллекция PNG» загрузите `neutral.png` и остальные изображения. Для первого прогона достаточно нейтрального рисунка, улыбки, нахмуренных бровей, удивления и грустного выражения.
4. Нажмите **«Запустить виртуальную камеру»** в HamsterCam. Если виртуальная камера уже запущена в OBS Studio, остановите её в OBS перед запуском вывода HamsterCam.
5. В Discord откройте «Настройки пользователя → Голос и видео» и выберите **OBS Virtual Camera**. Аналогично устройство выбирается в настройках камеры в Telegram, Zoom и Google Meet. В OBS оно добавляется как источник «Устройство захвата видео». Для такого захвата оставьте кнопку виртуальной камеры OBS выключенной, устройством управляет HamsterCam. [Документация pyvirtualcam](https://github.com/letmaik/pyvirtualcam#supported-virtual-cameras)
6. Проверьте нейтральное выражение, улыбку, нахмуренные брови и открытый рот. Затем уберите лицо из кадра, чтобы проверить возврат к нейтральному изображению. При остановке или выходе HamsterCam завершает передачу и освобождает устройство.

EXE хранит коллекцию в `%LOCALAPPDATA%\HamsterCam\assets\hamsters`. Кнопка «Открыть папку» показывает нужный каталог. Файлы добавляет пользователь.

## Запуск из исходников

Установите CPython 3.12 или 3.11 x64. [Загрузки Python](https://www.python.org/downloads/)

В папке проекта выполните команды.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1
```

`setup.ps1 -Python C:\путь\к\python.exe` позволяет указать конкретный интерпретатор. Скрипт устанавливает зависимости в `.venv-hamstercam` и проверяет SHA-256 модели Face Landmarker. Интернет нужен для получения зависимостей и модели при установке. Камера, распознавание и рендер работают без сети. В исходниках коллекция расположена в `assets/hamsters/`.

## Управление

- Видео отправляется в 1280×720 или 1920×1080 с целевыми 30 FPS. Фактическая частота вывода отображается рядом с именем устройства. При смене разрешения устройство переоткрывается, и в некоторых клиентах нужно снова выбрать источник.
- Прозрачный фон виден в предпросмотре. Поток OBS получает белую подложку, поскольку в этом режиме устройство принимает непрозрачное видео. Зелёный фон можно использовать с хромакеем. Пользовательский фон кадрируется по центру с сохранением пропорций.
- Автоматический режим использует blendshapes, ширину и раскрытие рта, симметрию уголков губ, движение бровей, закрытие глаз и позу головы. Правила сопоставляют видимые движения с десятью рисунками. Обычное моргание не переключает рисунок на сонный.
- Для калибровки сядьте прямо, расслабьте лицо, оставьте глаза открытыми и нажмите «Калибровать лицо». Если выражение обнаруживается слишком редко, поднимите чувствительность. Удержание и сглаживание влияют на задержку переключения. Приоритет задаёт порядок для одновременно видимых признаков.
- `Ctrl+1`–`Ctrl+9` и `Ctrl+0` в активном окне включают ручной режим. Порядок соответствует выпадающему списку, начиная с нейтрального выражения. При потере лица или камеры вывод возвращается к нейтральному PNG.
- «В трей» скрывает интерфейс и оставляет камеры в текущем состоянии. «Выход» в меню трея или закрытие окна завершает приложение. Настройки сохраняются в `%LOCALAPPDATA%\HamsterCam\settings.json`.

## Доступ к устройствам

- Если список физической камеры пуст, подключите устройство и нажмите ↻. Если устройство занято, закройте программы, которые захватывают эту камеру, и проверьте доступ настольных приложений к камере в параметрах Windows.
- Если Discord или браузер не показывает OBS Virtual Camera после установки OBS, перезапустите клиент. Если в Windows отсутствует само устройство, используйте официальный `virtualcam-install.bat` из установленного OBS Studio по [инструкции OBS](https://obsproject.com/kb/virtual-camera-troubleshooting).

## Сборка EXE

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Результат в `dist/HamsterCam/`. Распространяйте папку целиком. Python и MediaPipe входят в сборку. OBS Virtual Camera устанавливается на компьютере отдельно.

## Файлы проекта

| Путь | Назначение |
|---|---|
| `main.py`, `hamstercam/window.py`, `hamstercam/dialogs.py` | Запуск, интерфейс, коллекция и приоритет |
| `hamstercam/camera.py`, `hamstercam/pipeline.py` | OpenCV, отдельные потоки и обмен последними кадрами |
| `hamstercam/landmarks.py`, `hamstercam/expressions.py` | MediaPipe, pose, сглаживание и выбор выражения |
| `hamstercam/assets.py`, `hamstercam/render.py` | Импорт PNG, фон, компоновка и анимация |
| `hamstercam/virtual_camera.py` | Подача RGB-кадров в OBS Virtual Camera через pyvirtualcam |
| `models/face_landmarker.task` | [Официальная модель Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker) |
| `assets/hamsters/` | Оригиналы PNG пользователя |
| `requirements.txt`, `setup.ps1`, `build.ps1`, `HamsterCam.spec` | Зависимости, установка и сборка |
